## Terminology
- **ATS/RMS:** Applicant Tracking / Recruitment Management System.
- **DSS:** Decision Support System; supports rather than replaces human judgment.
- **Explainable matching:** recommendations with understandable matching evidence, gaps and unknowns.
- **Rediscovery:** reusing AYUDA's previously sourced candidates for new vacancies.
