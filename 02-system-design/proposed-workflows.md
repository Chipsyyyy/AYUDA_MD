# Workflows — Current and Proposed

## Existing AYUDA process (confirmed general stages)
Sourcing -> Paper Screening -> Interviewing -> Endorsement -> Feedback -> Job Offer / Onboarding Assistance. Recruiters use spreadsheets/Gantt charts, email, messaging and job platforms. External client stages may vary.

## Proposed recruiter workflow (team proposal)
1. Receive and register a vacancy from an existing client (M5).
2. Search previously sourced talent (M1) and accept new profiles where applicable (M6).
3. Extract résumé information and verify structured profile fields (M2).
4. Match eligible profiles to vacancy requirements, display reasons/gaps/unknowns (M3).
5. Recruiter confirms interest, availability and suitability.
6. Start or update a vacancy-specific application record and monitor AYUDA's six stages (M4).
7. Preserve the outcome in the candidate's reusable history.

## Proposed applicant workflow (pending validation)
Register -> provide résumé/preferences -> verify details -> browse and compare suggested jobs -> apply -> view authorized status updates. A preference is not a mandatory qualification; missing data must be flagged as unknown.

## Proposed client-company workflow (pending validation)
Authorized existing client enters/confirms job requirements -> AYUDA reviews and sources -> client sees only authorized endorsed profiles and explanation summaries -> provides feedback. **No general access to AYUDA talent pool.**

## Example: candidate with another offer
A candidate who accepted an offer elsewhere remains in records. Current availability and contact consent must be checked before future matching/approach. AYUDA's actual handling rules are pending its latest response.
