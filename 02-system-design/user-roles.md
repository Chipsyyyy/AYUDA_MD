# Proposed User Roles and Access Boundaries

| Role | Proposed access | Status |
|---|---|---|
| Talent Acquisition Lead/Admin | Manage recruitment users, candidates, vacancies, assignments and monitoring | Core proposed |
| Recruiter | Search/review candidates, verify extracted data, match and endorse, track activities | Core proposed |
| Applicant | Manage own profile, preferences, view jobs/recommendations, apply | Pending validation |
| Existing client representative | Submit/confirm vacancy requirements and view permitted endorsed candidates/feedback | Pending validation |

## Security principles
- Role-based access and least privilege; client companies must not browse the entire talent database.
- Candidate document access restricted by authorized purpose.
- Explain recommendations without exposing unrelated candidate records.
- Keep human approval for endorsements and hiring.
- Record changes and verification provenance; do not use unverified extracted data as confirmed fact.
- Actual permissions and data-sharing policies must be validated with AYUDA.
